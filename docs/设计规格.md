## 2. 核心分析口径（冻结）

慢性病标志位（`1=是, 2=否, 7=不知道, 9=拒答`；7/9 → NULL 剔除）：
| 字段 | 含义 | 变量（跨年统一后） |
|---|---|---|
| has_diabetes | 糖尿病 | DIABETE4（2023 起 1/2/3/4 语义：1=是 2=妊娠期 3=否 4=糖尿病前期） |
| has_mi | 心梗 | CVDINFR4 |
| has_chd | 冠心病 | CVDCRHD4 |
| has_stroke | 卒中 | CVDSTRK3 |
| has_copd | 慢阻肺 | CHCCOPD2(2019–2020) / CHCCOPD3(2021–2023) |
| has_asthma | 哮喘 | ASTHMA3 |
| has_kidney | 慢性肾病 | CHCKDNY2 |
| has_depression | 抑郁 | ADDEPEV3 |

派生指标：
- `chronic_count` = 上述 8 个标志位之和（NULL 视为 0，但**当 8 项全为 NULL 时该行标记为标签不可用**）
- **主标签 `multimorbidity` = chronic_count ≥ 2**（共病）
- 次任务标签 `has_diabetes`

可干预危险因素（建模特征 + 干预靶点）：
- `bmi` = _BMI5/100（_BMI5 为 ×100 整数）；`obese` = bmi ≥ 30
- `smoker3` = _SMOKER3（1 每日吸 / 2 部分日 / 3 曾经 / 4 从不）
- `phys_activity` = _TOTINDA（1 有 / 2 无）
- `heavy_drink` = _RFBING6（2022+）
- `genhlth` = GENHLTH（1 优 … 5 差）；`poor_health` = _RFHLTH
- `menthlth`/`physhlth` = 近30天不良天数
- `checkup` = CHECKUP1；`medcost` = MEDCOST/MEDCOST1（费用障碍）；`persdoc` = PERSDOC3
- `diffwalk` = DIFFWALK
- 人口学：`sex`=_SEX,`age`=_AGE80,`age_grp`=_AGEG5YR,`race`=_MRACE1/_MRACE2 调和,`hispanic`=_HISPANC,`educa`=EDUCA,`income_grp`=_INCOMG/_INCOMG1,`employ`=EMPLOY1,`marital`=MARITAL,`veteran`=VETERAN3,`state_fips`=_STATE,`month`=FMONTH

统一规则：
1. 缺失码 7（不知道）/ 9（拒答）/ 77/99 等 → NULL
2. BMI 异常：<10 或 >70 → NULL（并在质量报告中计数）
3. 年度不一致变量用**调和映射表**统一，映射表写入 `docs/数据字典.md`
4. 每条记录主键 **`seq_key = f"{year}_{_STSTR}_{SEQNO}"`**
   （实测更正：SEQNO 是层内序号，单列不唯一。2019 年 418,268 行只有 17,419 个不同 SEQNO；(_STSTR, SEQNO) 组合去重后 = 418,268 = 全部行，2023 年同理 433,323。_PSU 与 SEQNO 数值完全相同，不能用于补唯一性。原定义 `{year}_{SEQNO}` 会撞主键。）

## 5. API 契约（统一信封）

```json
{"code":0,"message":"ok","data":<payload>,"traceId":"<uuid>","timestamp":<ms>}
```
错误：code≠0，HTTP 200 以外同时给 message。所有接口带 `X-Response-Time`。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | /api/v1/health | 健康检查（DB 连接 + 行数） |
| GET | /api/v1/overview | 总览 KPI（总样本/慢病数/共病率/年份跨度） |
| GET | /api/v1/chronic/prevalence?year=&state= | 各慢病患病率 |
| GET | /api/v1/trend?metric= | 指标年度趋势 |
| GET | /api/v1/risk/factors?year= | 危险因素暴露率 |
| GET | /api/v1/risk/stratify | 风险分层分布 |
| GET | /api/v1/geo/states?metric= | 州级指标（地图） |
| GET | /api/v1/model/metrics | 模型指标与对比 |
| POST | /api/v1/predict | 在线个体风险预测 |
