## 3. 必须设置的环境变量（PySpark）

PySpark 是 **JVM 进程**，未设置 JAVA_HOME / SPARK_HOME 会直接 JVM 启动失败
（典型报错：`Could not find or load main class org.apache.spark.deploy.SparkSubmit`）。

```powershell
$env:JAVA_HOME   = "D:\jdk17"                                  # 必填：JDK 17 根目录（含 bin\java.exe）
$env:SPARK_HOME  = "D:\sparkhome"                              # 必填：Spark 根目录（含 bin\spark-submit）
$env:PYSPARK_PYTHON = "D:\期末作业\.venv\Scripts\python.exe"  # 必填：executor 使用的 Python
$env:PYSPARK_DRIVER_PYTHON = $env:PYSPARK_PYTHON
$env:PATH = "$env:JAVA_HOME\bin;$env:SPARK_HOME\bin;$env:PATH"
```

bash（Git Bash / WSL 同理）：

```bash
export JAVA_HOME="D:/jdk17"
export SPARK_HOME="D:/sparkhome"
export PYSPARK_PYTHON="D:/期末作业/.venv/Scripts/python.exe"
export PATH="$JAVA_HOME/bin:$SPARK_HOME/bin:$PATH"
```

> **API 服务本身不需要 Spark**（只读 SQLite + joblib 模型），上述变量仅在跑数据管道时需要。

## 7. 常见问题（FAQ）

### 7.1 中文路径导致 Spark 启动 / classpath 失败

**现象**：PySpark 启动时报 `java.lang.ClassNotFoundException: org.apache.spark.deploy.SparkSubmit`、
`Malformed classpath`、`Could not find or load main class`，或 Hadoop `winutils.exe` 相关错误。

**原因**：Spark/JVM 在 Windows 上把路径拼进 `-cp` classpath，工程或 Spark 安装目录含中文
（本项目工作根目录 `D:\期末作业` 就是中文）时，JVM 读取的 classpath 编码与文件系统不一致，
导致类加载失败；`JAVA_HOME`/`SPARK_HOME` 落在中文路径下同理。

**处理**（任选其一，推荐第 1 条）：

1. **把 JDK 与 Spark 装在纯英文路径**，只用环境变量指过去（本项目已按此配置）：
   `JAVA_HOME=D:\jdk17`、`SPARK_HOME=D:\sparkhome`。
2. 让 Spark 的临时目录也避开中文：`$env:SPARK_LOCAL_DIRS="D:\sparktmp"`、
   `$env:TEMP="D:\sparktmp"; $env:TMP="D:\sparktmp"`。
3. 若仍然失败，把整个工程复制到纯英文路径（如 `D:\project\chronic`）后重跑管道；
   或用符号链接绕过：`mklink /D D:\work D:\期末作业`，在 `D:\work` 下执行。
4. 只做联调、不跑 Spark 时，可跳过第 3 步的清洗与 EDA，直接使用已有的
   `data/processed/*.parquet` 与 `db/chronic_risk.db`。

### 7.2 启动报 `ModuleNotFoundError: No module named 'api'`

当前目录不对。必须先 `cd` 到工程根目录（含 `api/` 的那一级）再执行
`python -m uvicorn api.main:app`。

### 7.3 端口 8000 被占用（`[Errno 10048]`/`EADDRINUSE`）

```powershell
netstat -ano | findstr :8000          # 找到 PID
taskkill /PID <PID> /F                # 结束占用进程
# 或临时换端口（注意：文档与前端默认 8000）
python -m uvicorn api.main:app --port 8001
```

### 7.4 接口返回 `code=1003`（数据库未就绪）

`db/chronic_risk.db` 不存在或缺少 `fact_brfss` 表。先执行
`python pipeline/06_build_db.py` 建库，再调 `/api/v1/health` 确认 `factRows` 非 0。
此时 `/api/v1/health` 本身不会报错，而是返回 `status=degraded`。

### 7.5 接口返回 `code=1001`（模型未就绪）

`artifacts/model/model.joblib` 不存在（训练步未跑）。执行
`python pipeline/05_train.py` 生成模型后即可在线预测；模型缺失时只有 `/api/v1/predict` 受影响，
其余 8 个接口正常。

### 7.6 控制台中文显示为乱码

Windows 控制台默认 GBK。执行 `chcp 65001` 切 UTF-8，或在 PowerShell 7 中运行；
接口返回的 JSON 本身是 UTF-8，浏览器/前端显示不受影响。

### 7.7 pytest 报 `ModuleNotFoundError: tests`

必须从工程根目录执行 `python -m pytest tests -q`（`tests/` 是包，rootdir 为工程根）。

### 7.8 首次请求较慢（1~3 秒）

明细表约 213 万行，`/api/v1/geo/states` 与 `/api/v1/risk/stratify` 需要全表扫描。
服务对聚合结果做了 30 秒内存缓存（环境变量 `API_CACHE_TTL=0` 可关闭），二次请求通常在 10 ms 内。


### 7.9 打开 /docs 页面一片空白

`/docs` 的 Swagger UI 静态资源（`swagger-ui.css` / `swagger-ui-bundle.js`）默认从
`cdn.jsdelivr.net` 加载，**无外网时页面会空白**，但接口本身完全正常、可正常调用。
离线核对接口清单请改用 `http://127.0.0.1:8000/openapi.json`（本地实时生成，含全部 9 个路径与参数定义），
或用本文档 / docs/接口文档.md 逐条比对。

### 8.1 JWT 鉴权用法

    # 1) 登录换令牌
    curl -X POST http://127.0.0.1:8000/api/v1/auth/login -H "Content-Type: application/json" -d '{"username":"demo","password":"demo12345"}'

    # 2) 带令牌调用受保护接口
    curl -X POST http://127.0.0.1:8000/api/v1/predict -H "Authorization: Bearer <上一步的 accessToken>" -H "Content-Type: application/json" -d '{"age":68,"sex":1,"bmi":31.5,"smoker3":1,"phys_activity":0}'

设计与取舍：**查询类接口保持公开**（评阅人无需登录即可看大屏），
只有写操作 /predict 需要令牌——既满足"JWT 鉴权"加分项，又不增加演示门槛。

密钥从环境变量 AUTH_SECRET_KEY 读取；未设置时进程内随机生成并在启动告警，
因此**代码库中不含任何密钥**。演示账号通过 AUTH_USERS 注入，密码经 bcrypt 哈希后驻留内存。
